# Course Planner & Deadline Tracker

Final Year Project – Flask web application designed to help university students manage coursework, deadlines, and academic workload.

## Features
- User registration, login, and logout
- Task creation, editing, deletion, and status updates
- Deadline classification (Overdue, Due Today, Due Soon)
- Module-based organisation
- Calendar view
- CSV export
- ICS calendar export
- User settings
- Dark mode support
- CSRF protection and session-based authentication

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## How to Run the Application
1. Install dependencies:
   pip install -r requirements.txt

2. Run the application:
   python app.py

3. Open in browser:
   http://127.0.0.1:5000/
